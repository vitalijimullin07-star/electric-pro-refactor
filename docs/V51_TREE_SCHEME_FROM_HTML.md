# V51 Tree Scheme From HTML


## Главное

- схема строится как дерево;
- используется `schemeTree.children`;
- `calculatePositions()` расставляет листья по X;
- родительский аппарат ставится по центру между дочерними;
- `drawTree()` рекурсивно рисует ветки;
- кнопка находится в конфигураторе щита;
- схема открывается только по нажатию кнопки.
