# V79 Clean Database Engine


- V68 lazy render;
- V69 mass tools;
- V72 sync.


- `04-database-v79-clean-engine.js`

## Что исправляет

- новая база не должна зависать;
- очистка моей базы очищает все старые хвосты;
- добавление с сервера в мою базу сохраняется;
- категория/подкатегория создаются в чистом источнике;
- редактирование цены/единицы доступно только в моей базе.

## Проверка

1. Открыть новую базу.
2. В базе сервера выбрать позиции.
3. Нажать `+ Добавить выбранные в мою базу`.
4. Обновить страницу.
5. Моя база должна сохранить позиции.
6. Нажать `Очистить мою базу`.
7. Обновить страницу.
8. Моя база должна остаться пустой.
