# V61 Clear My Database Guard


> В режиме `Моя база` после очистки работы всё равно оставались.

## Что сделано


- `public/js/04-database-clear-my-guard.js`

## Логика


- `EP_MY_MAT`
- `EP_MY_WORK`
- `userMatDB`
- `userWorkDB`
- если активна `Моя база`, то также:
  - `matDB`
  - `workDB`


## Проверка

1. Включить `Моя база`.
2. Нажать `Очистить мою базу`.
3. Материалы должны стать 0.
4. Работы должны стать 0.
5. После перезагрузки работы не должны вернуться.
