# V68 Database Lazy Render


## Главное



`🧪 Открыть базу V68 без зависаний`

## Логика

- категории рендерятся списком;
- позиции внутри категории не создаются, пока категория закрыта;
- при открытии категории строится только эта категория;
- цена и единица редактируются через EP_DB.

## Проверка

1. Открыть базу данных.
2. Нажать `🧪 Открыть базу V68 без зависаний`.
3. Открыть категорию `Автоматика`.
4. Сайт не должен зависнуть.
