# V80 Database Architecture

## Главная логика базы

1. База сервера — это источник/витрина позиций для мастера.
2. Моя база — это личный рабочий редактор мастера.
3. Открыть новую базу — открывает именно Мою базу как файловый менеджер.
4. Админ в Базе сервера получает расширенные права.

---

## База сервера для мастера


- открыть Базу сервера;
- выбрать материалы и работы;
- нажать Добавить выбранные в мою базу.


- редактировать цену;
- редактировать единицу измерения;
- перемещать позиции;
- удалять позиции;
- импортировать напрямую в сервер;
- экспортировать сервер;
- использовать ИИ-импорт напрямую в сервер.

---

## Моя база


- видеть свои материалы и работы;
- редактировать цену;
- редактировать единицу измерения;
- создавать категории;
- создавать подкатегории;
- перемещать позиции;
- удалять позиции;
- очищать свою базу;
- импортировать файлы;
- экспортировать файлы;
- использовать ИИ-импорт из фото, Excel, текста и скриншотов.



---

## База сервера для админа


- редактировать цену;
- редактировать единицу измерения;
- создавать категории;
- создавать подкатегории;
- перемещать позиции;
- добавлять позиции;
- удалять позиции;
- импортировать;
- экспортировать;
- использовать ИИ-импорт;
- смотреть базы мастеров;
- добавлять позиции из базы мастера в серверную базу;
- добавлять с ценой или без цены.
