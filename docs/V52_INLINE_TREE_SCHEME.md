# V52 Inline Tree Scheme


## Что изменено

- схема больше не открывается отдельным окном поверх приложения;
- схема раскрывается прямо под кнопкой `📐 Схема щита`;
- блок остаётся внутри той же панели конфигуратора щита;
- древовидная логика V51 сохранена.

## Проверка

1. Открыть конфигуратор щита.
2. Нажать `📐 Схема щита`.
3. Схема должна раскрыться под кнопкой внутри белой панели.
4. Ветки схемы должны расходиться деревом, а не идти столбиком.
