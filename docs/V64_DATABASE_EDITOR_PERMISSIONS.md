# V64 Database Editor Permissions


1. В `Моя база` мастер может редактировать цену.
2. В `База сервера` мастер не редактирует напрямую.
3. В массовом управлении исправлена пустая подкатегория при перемещении.
4. Подкатегории заполняются из активной базы.

## Проверка

1. Открыть `Моя база`.
2. Цена должна редактироваться.
3. Массовое управление:
   - выбрать позицию;
   - выбрать категорию;
   - подкатегория должна заполниться;
   - перемещение не должно зависать на пустом окне.
4. Открыть `База сервера` обычным мастером:
   - прямое добавление/редактирование должно быть заблокировано.
