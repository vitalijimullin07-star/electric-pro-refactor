# V84 Copy Server To My Database


`База сервера` → `Моя база V83`

## Как работает

1. Мастер открывает `База сервера`.
2. Выбирает позиции галочками.
3. Нажимает `+ Добавить выбранные в мою базу`.
4. Выбранные позиции сохраняются в новую личную базу:
   - `ep_my_db_materials_v83`
   - `ep_my_db_works_v83`
5. После перезагрузки позиции остаются в `my-database.html`.

## Важно

V84 только связывает серверную витрину с новой личной базой.
