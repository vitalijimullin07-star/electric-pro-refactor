# V67 Database Core


- `window.EP_DB`

## Что умеет

- активная база:
  - `my`
  - `server`
- роль:
  - `master`
  - `admin`
- права:
  - мастер редактирует только свою базу;
  - серверную базу напрямую редактирует только админ;
- разрешённые поля редактирования:
  - `price`
  - `unit`
- заявки на сервер:
  - `createServerProposal(type, item, { withPrice })`

## Важно

V67 почти не меняет UI. Это фундамент перед нормальным рендером базы V68.
