# V32 Single Line Scheme Module


- `public/js/06-single-line-scheme.js`

## Что внутри

- Отдельный редактор однолинейной схемы
- SVG-символы:
  - автомат MCB
  - УЗО
  - дифавтомат
  - рубильник
  - реле напряжения
  - счётчик
  - УЗИП
  - контактор
- Дерево схемы
- Отрисовка схемы
- Выбор аппарата кликом
- Редактирование:
  - тип
  - ID
  - номинал
  - название группы
  - кросс-модуль
- Добавление аппарата вниз
- Удаление узла
- Сохранение в localStorage
- Кнопка запуска на экране: `📐 Схема`

## Важно

`00-core.js` не трогался. Модуль подключается безопасно и работает отдельно.
