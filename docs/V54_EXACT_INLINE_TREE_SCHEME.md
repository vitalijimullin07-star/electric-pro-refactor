# V54 Exact Inline Tree Scheme


## Что изменено

- кнопка вставляется точно под кнопкой `Ручная сборка`;
- схема раскрывается внутри этого же белого окна конфигуратора щита;
- схема сделана через iframe, поэтому не вылезает слева/справа/поверх;
- древовидная логика сохранена:
  - `schemeTree.children`;
  - `calculatePositions`;
  - `drawTree`;
  - рекурсивные ветки.

## Проверка

1. Открыть конфигуратор щита.
2. Под кнопкой `Ручная сборка` должна быть кнопка `📐 Схема щита`.
3. Нажать кнопку.
4. Схема должна раскрыться прямо под кнопкой внутри белого окна.
