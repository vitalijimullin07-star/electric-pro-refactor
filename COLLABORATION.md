# Общая работа Claude и Codex

Этот файл — общий журнал задач, правок и проверок Electric Pro. Создан по просьбе владельца 13.11.2026. Оба помощника могут анализировать, редактировать код и проверять изменения. Роли назначаются для конкретной задачи, а не закрепляются навсегда.

## Начало работы

1. Прочитать актуальные `CLAUDE.md`, `AGENTS.md` (если есть) и этот файл в нужной ветке.
2. Проверить текущий main, рабочее дерево и открытые PR. Не считать локальную копию или прошлый отчёт актуальными автоматически.
3. Руководствоваться последним заданием владельца. Аудит сам по себе не означает поручение исправлять код.
4. Перед правками записать задачу, исполнителя, базовый SHA, ветку и затрагиваемые файлы. Публиковать запись в рабочей ветке/PR, чтобы она была видна другому помощнику.
5. Если другой исполнитель уже меняет те же файлы, согласовать передачу через владельца или разнести работу по независимым частям. Не перезаписывать чужие правки.

Это журнал, а не техническая блокировка файлов: два помощника могут прочитать его одновременно. Проверка свежего main и PR перед началом и перед слиянием обязательна. Запись в файле не запускает другого помощника и не отправляет ему уведомление.

## Как передавать результат

- Работать в отдельной ветке; соблюдать процесс PR и слияния из `CLAUDE.md` в пределах поручения владельца.
- В конце задачи обновить её запись: итог, изменённые файлы, commit/PR, выполненные проверки, ограничения и следующий шаг.
- Различать «реализовано», «проверено тестами», «проверено в браузере» и «проверено на устройстве». Указать SHA, на котором проходили проверки.
- Для ошибки указать сценарий воспроизведения, ожидаемое и фактическое поведение. Для производительности — проект, устройство/браузер, замедление CPU и метод измерения.
- Не объявлять весь проект исправленным только по зелёным тестам. Не выдавать измерения другого исполнителя за собственные.
- Сохранять незавершённые задачи и историю. Передавать исходный смысл замечания, даже если реализация изменилась.
- Проверяющий по возможности отличается от автора правок; это не обязательное согласование и не повод останавливать порученную работу.
