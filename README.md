# Electric Pro Refactor — V29.2 Visual Match

Чистая пересборка оболочки Electric Pro с визуалом как в основном проекте.

Цель:
- сохранить старый стеклянный визуал;
- не использовать временные слои;
- держать один router, один app-shell и один visual-settings модуль;
- защищённые блоки Claude подключать позже как отдельные модули.

Защищённые зоны:
- БД;
- конфигуратор щита;
- Материалы;
- Работа;
- ручная однолинейная схема.
