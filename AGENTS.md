# Работа помощников в этом репозитории

Перед началом задачи прочитайте [CLAUDE.md](CLAUDE.md) — технические правила проекта — и [COLLABORATION.md](COLLABORATION.md) — общий журнал Claude и Codex.

Оба помощника могут вносить изменения по поручению владельца. В журнале фиксируйте исполнителя, область правок, ветку/PR, результаты проверок и оставшиеся вопросы. Перед работой сверяйте актуальный main и открытые PR; журнал не является блокировкой и не обеспечивает автоматическую связь между помощниками.

Актуальные инструкции владельца имеют приоритет. Не перезаписывайте чужие изменения и не считайте наличие замечания в журнале поручением исправлять его.
